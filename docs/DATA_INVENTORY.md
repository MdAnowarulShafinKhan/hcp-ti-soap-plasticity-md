# Data inventory

## Included

- Complete LAMMPS input scripts and per-case metadata.
- HCP Ti starting structures for 4k, 32k, and 108k atoms.
- Kim-Lee-Baskes Ti MEAM parameter files and OpenKIM/NIST provenance metadata.
- Raw scalar `equilibration.csv` and `mechanics.csv` for all four runs.
- Production stdout logs for all four runs.
- Selected `equilibrated.data` and `final_deformed.data` states for all four runs.
- Processed mechanical curves and corrected metric JSON files.
- PTM fractions for every saved analyzed frame.
- Global SOAP descriptors, frame metadata, SOAP-distance tables, combined MDS coordinates, and MDS distance matrix.
- Exploratory Isolation Forest aggregate scores (kept for transparency, not used as the central result).
- All GitHub figures and CSV/XLSX result summaries.

## Intentionally omitted

- `trajectory.lammpstrj`: too large for a normal GitHub repository in the 108k cases and reproducible from included inputs.
- Restart binaries: large, backend/version-dependent recovery files that are not needed to document the completed results.
- `soap_local_samples.npz`: approximately 29 MB per case, unnecessary for the core GitHub figures and too large for convenient browser upload. They can be regenerated by running `03_soap.py` after regenerating trajectories.

The omission of these large intermediate files means the repository stays practical to clone while preserving the inputs and processed evidence needed for the project conclusions.
