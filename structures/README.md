# HCP Ti starting structures

This directory contains the undeformed HCP Ti starting configurations used in the molecular-dynamics simulations.

## Structure generation

All three structures were generated by the repository author using Atomsk from ideal HCP Ti with:

* lattice parameter \(a = 2.95\) Å
* lattice parameter \(c = 4.68\) Å
* H1 = [10-10]
* H2 = [1-210]
* H3 = [0001]

The `[0001]` direction corresponds to the HCP c-axis and is aligned with the simulation z direction used for c-axis compression.

The initial oriented HCP cell was converted to an equivalent orthogonal cell with Atomsk's `-orthogonal-cell` option before replication.

| Structure     |  Replication | Number of atoms |
| ------------- | -----------: | --------------: |
| `Ti_4k.lmp`   | 10 × 10 × 10 |           4,000 |
| `Ti_32k.lmp`  | 20 × 20 × 20 |          32,000 |
| `Ti_108k.lmp` | 30 × 30 × 30 |         108,000 |

## Reproducing the structures

The complete generation commands are provided in:

`generate_structures.sh`

With Atomsk installed, run:

```bash
chmod +x generate_structures.sh
./generate_structures.sh
```

This will regenerate all three LAMMPS data files.
