# Third-party data and potential notice

## Ti MEAM potential

The files `potentials/library.meam` and `potentials/Ti.meam` correspond to the Ti MEAM potential developed by Young-Min Kim, Byeong-Joo Lee, and M. I. Baskes:

> Y.-M. Kim, B.-J. Lee, M. I. Baskes, "Modified embedded-atom method interatomic potentials for Ti and Zr," *Physical Review B* **74**, 014101 (2006). DOI: 10.1103/PhysRevB.74.014101.

The model metadata identifies the OpenKIM/NIST entry `MEAM_LAMMPS_KimLeeBaskes_2006_Ti__MO_472654156677_001`, DOI `10.25950/f8f658f3`.

The original model-package license text is preserved as `potentials/POTENTIAL_LICENSE` (GNU LGPL v2.1). The accompanying `kimspec.edn`, `kimprovenance.edn`, and citation file are retained for provenance.

This repository does **not** claim authorship of the interatomic potential.

## Initial structures

The starting HCP Ti structures `Ti_4k.lmp`, `Ti_32k.lmp`, and `Ti_108k.lmp` were generated by the repository author using Atomsk.

The structures were constructed as ideal HCP Ti crystals using lattice parameters \(a = 2.95\) Å and \(c = 4.68\) Å, with crystallographic directions H1=[10-10], H2=[1-210], and H3=[0001]. An equivalent orthogonal simulation cell was generated before replication.

The exact Atomsk commands used were:

```bash
atomsk --create hcp 2.95 4.68 Ti orient [10-10] [1-210] [0001] \
  -orthogonal-cell -duplicate 10 10 10 Ti_4k.lmp

atomsk --create hcp 2.95 4.68 Ti orient [10-10] [1-210] [0001] \
  -orthogonal-cell -duplicate 20 20 20 Ti_32k.lmp

atomsk --create hcp 2.95 4.68 Ti orient [10-10] [1-210] [0001] \
  -orthogonal-cell -duplicate 30 30 30 Ti_108k.lmp
```

The resulting structures contain 4,000, 32,000, and 108,000 Ti atoms, respectively. They are included directly in the repository so that the starting configurations and complete molecular-dynamics workflow can be reproduced without an external file store.

Atomsk was developed by Pierre Hirel; the software citation is provided in the repository references.
